# 사기싹제로 (ScamSproutZero)

**결제 전에, 판매자의 위험 신호와 그 근거를 확인하세요.**

더치트 같은 기존 사기조회 서비스는 이미 피해가 신고된 판매자만 찾아줍니다.
사기싹제로는 아직 피해 신고가 없는 판매자도 사업자정보 불일치·가격 이상치·
결제 유도 문구 등 여러 근거를 교차검증해서 결제 전에 위험 신호를 알려줍니다.

## 무엇을 하는가

상품 페이지 링크를 넣으면:

1. 페이지에서 판매자 정보(스토어명, 사업자정보 고시, 가격, 상품 설명)를 자동으로 가져오고
2. 여러 위험 신호를 교차검증합니다 — 스토어 표시명과 실제 사업자명 불일치, 시장가 대비 이상 저가,
   신규 사업자 여부, 주거용 건물 주소 여부, 플랫폼 외부 결제 유도 문구, 관련 피해 제보 등
3. 결정론적 규칙 엔진이 0~100점의 위험도를 계산하고
4. 왜 이 점수가 나왔는지, 어떤 조건이 확인되면 위험도가 낮아지는지("반사실 설명")까지 알려줍니다

정적 페이지 읽기가 막힌 사이트(봇 차단이 있는 대형 쇼핑몰 등)는 헤드리스 브라우저로
화면을 캡처해서 최소한 눈으로 확인할 수 있게 하고, 필요한 값을 직접 입력/수정할 수 있습니다.

## 설계 원칙

- **근거 없이는 의심하지 않는다.** 확인할 수 없는 신호는 추측하지 않고 판단을 보류합니다.
- **점수는 LLM이 아니라 결정론적 규칙 엔진이 계산합니다.** LLM은 페이지에서 근거를 추출하고
  자연어로 설명하는 역할만 맡습니다 — 같은 근거에는 항상 같은 점수가 나옵니다.
- **낮은 신뢰도의 근거로 강한 주장을 하지 않습니다.** 예를 들어 "판매자 신원 불일치" 같은
  강한 신호는 공식 API나 플랫폼 공개 정보로만 판단하고, 출처가 불명확한 웹검색·LLM 추론만으로는
  해당 신호를 인정하지 않습니다.

## 시작하기

```bash
pip install -r requirements.txt
playwright install chromium   # 정적 요청이 막힌 페이지의 스크린샷 폴백에 필요
streamlit run app.py
```

`http://localhost:8501` 접속. 키 없이도 규칙 기반 폴백으로 전부 동작합니다.

| 환경변수 | 없으면 | 있으면 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 문자열 비교로 신원 판단, 템플릿으로 설명 생성 | Claude가 신원 관계 추론 + 근거 기반 설명 생성 + 스크린샷 vision 추출 |
| `NTS_API_KEY` | 사업자등록번호 형식(체크섬)만 검증 | 국세청 사업자등록 상태를 실제로 조회 |

## 프로젝트 구조

```
app/
  risk_config.json   위험도 스코어링 규칙 (가중치, hard gate, 근거 출처별 신뢰도)
  risk_engine.py     evidence -> 0~100점 결정론적 계산 + 반사실 설명
  evidence.py        판매자 정보 -> risk_engine이 쓰는 evidence로 변환
  explain.py         위험도 판단을 자연어 리포트로 변환
  fetcher.py         구매 링크에서 판매자 정보 자동 수집
  screenshot.py      정적 수집이 막히면 헤드리스 브라우저로 화면 캡처 + vision 추출
app.py               Streamlit 화면
tests/               pytest 테스트
```

## 테스트

```bash
pip install -r requirements-dev.txt
pytest
```

## 알려진 제한사항

- 대형 커머스 사이트 다수가 JS 렌더링과 봇 차단을 쓰고 있어, 정적 페이지 읽기만으로는
  핵심 정보(특히 사업자정보 고시)를 못 가져올 수 있습니다. 이 경우 스크린샷으로 대체되고
  사용자가 직접 값을 채워야 합니다.
- 외부 평판/피해 제보 검색은 아직 실제 웹검색 연동이 없고, 구조화된 결과를 넣어주는
  인터페이스만 있습니다.
- 국세청 사업자등록 상태조회 API 연동은 아직 실제 서비스키로 검증되지 않았습니다.
